# Local data files

Place the original `Stats2work.RData` file here to load the saved RStudio workspace using `R/00_load_workspace.R`. Do **not** commit the workspace to GitHub until the underlying data sources and redistribution permissions have been checked. The file is ignored by `.gitignore`.

This is a snapshot of saved objects, not a reproducible data-import pipeline. Rebuilding the underlying data from raw sources remains future work.
